01 Design and build Retired

Code Less Traveled

The site for my former web consultancy. The business is closed. The design earned a place here anyway, so it is preserved, working, as it was built.

The design
Swiss typographic layout on a hairline grid. Type carries the page; the grid is visible on purpose, as a rule the layout keeps rather than a scaffold it hides.
The build
The custom logo mark is positioned against live font metrics, measured at runtime with Canvas TextMetrics. Whichever way the browser resolves the typeface, the mark sits where it was drawn to sit against the wordmark.

02 Client engagement

Crow and Moon Enchantments

A site for a handmade-goods business, written to sound like the person behind the counter.

The design
Product copy written in the owner's voice. A shop like this sells on who made the thing, so the site needed to read like her, not like a catalogue.
The build
An Eleventy 3 static build with a modular SCSS architecture on the Sass @use module system. Static, fast, and cheap to host for as long as the shop wants it.
  • Eleventy 3
  • Sass
  • Copywriting

03 Client engagement

Joel Baker Counseling

A practice site for a counselor, where clear structure matters more than anything clever.

The design
Information architecture first. The owner wrote most of the copy; I edited and shaped it so a visitor finds what they came for without working at it.
The build
Eleventy 3 static build on the same modular Sass architecture. Fully accessible and keyboard-navigable from the start, not patched in after an audit.
  • Eleventy 3
  • Sass
  • Accessibility

04 Design and build

ben.atlarge

The portfolio for my pet photography. The photographs are the point, so the interface stays out of their way.

The design
A master and detail gallery: one photograph large, the rest in reach. Quiet chrome, so every frame is judged on the frame.
The build
Built from real button elements rather than click handlers on divs, so the keyboard works without special effort. With JavaScript off, it degrades to a plain stacked gallery. Accessibility as a structural decision.
